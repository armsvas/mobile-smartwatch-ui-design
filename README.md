# HoyConnect — Mobile & Smartwatch UI Design

## Project Overview

HoyConnect is a university UI/UX design project exploring user-friendly interfaces for mobile phones and smartwatches using Figma.

## Technologies Used

- Figma — Wireframing and interface prototyping
- UI/UX Design — Layout, navigation and user experience
- Accessibility — Designing with usability and different user needs in mind

## Project Features

- Mobile interface prototype
- Smartwatch interface prototype
- Navigation and interaction design
- Application of accessibility and usability principles

## Project Purpose

This project allowed me to explore user-centred design principles and consider how interfaces should adapt across devices with different screen sizes and interaction requirements.
